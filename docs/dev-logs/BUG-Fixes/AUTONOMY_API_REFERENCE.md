# VaporTrace Full Autonomy - API Reference & Integration Guide

## Quick Reference

### Core Engine Functions

#### ProcessChain(chainID string)
**Location:** `pkg/engine/core.go`
**Purpose:** Execute a sequence of tactical actions with precondition validation
**Signature:** `func ProcessChain(chainID string)`

**Usage:**
```go
// Auto-generated by ProcessExploitResult()
ProcessChain("chain_1_1707325843123456789")

// Or manually:
ProcessChain("chain_BOLA_to_K8S")
```

**Behavior:**
1. Filters ActionBuffer by ChainID
2. Validates PreCondition for each action (checks GlobalDataSilo)
3. Executes action if condition met
4. Captures loot in DataSilo
5. Logs to LogBuffer (prevents TUI freeze)

### Data Storage (DataSilo)

**Location:** `pkg/logic/store.go`

#### GlobalDataSilo Methods

```go
// Store a value
GlobalDataSilo.Set("k8s_token", "eyJ0eXAiOiJKV1QiLCJhbGc...")

// Retrieve a value
if val, ok := GlobalDataSilo.Get("k8s_token"); ok {
    token := val.(string)

token := GlobalDataSilo.GetString("k8s_token")

// Check existence (for PreConditions)

    // Execute action that needs k8s_token
}

// List all keys (for debugging)
keys := GlobalDataSilo.List()
```

#### MimicTraffic(req *http.Request, targetProfile string)
**Purpose:** Set realistic browser/client headers
**Signature:** `func MimicTraffic(req *http.Request, targetProfile string)`

**Profiles:**
- `"iOS"` - Safari on iPhone
- `"Chrome-MacOS"` - Chrome on macOS (default)
- `"Firefox-Windows"` - Firefox on Windows
- `"EdgeBrowser"` - Microsoft Edge
- `"Safari"` - Safari on macOS
- `"Bot"` - VaporTrace generic bot header

**Usage:**
```go
// Already called in RoundTrip with Chrome-MacOS default
req, _ := http.NewRequest("GET", url, nil)
MimicTraffic(req, "iOS") // Mimic iPhone
response, _ := GlobalClient.Do(req)
```

### Autonomous Chaining (NeuroEngine)

**Location:** `pkg/engine/neuro_engine.go`

#### ProcessExploitResult(exploit TacticalAction, loot string)
**Purpose:** Analyze exploit results and auto-generate follow-up exploits
**Signature:** `func (n *NeuroEngineCore) ProcessExploitResult(exploit TacticalAction, loot string)`

**Usage:**
```go
// Called after successful exploit
loot := "Bearer eyJ0eXAi..." // Captured JWT token
ProcessExploitResult(lastAction, loot)

// Result: 
// - Stores loot in GlobalDataSilo with key "loot_from_<ID>"
// - Generates JWT_BYPASS TacticalAction
// - Sets PreCondition = "loot_from_<ID>"
// - Queues to ActionBuffer with ChainID
```

**Auto-Generated Actions (based on loot type):**

| Detected Data | Generated Action | PreCondition | Loot Key |
|---------------|------------------|--------------|----------|
| k8s_token | CROSS_TENANT_LEAKAGE | k8s_token | k8s_namespaces_* |
| bearer/auth token | LATERAL_MOVEMENT | token_key | lateral_result_* |
| AWS access_key | CLOUD_PIVOT | aws_creds | aws_enumerate_* |
| JWT token | JWT_BYPASS | jwt_token | jwt_bypass_* |
| Generic credential | PRIVILEGE_ESCALATION | cred_key | privesc_* |

### Blue-Team Remediation

**Location:** `pkg/engine/remediation.go`

#### SuggestFix(exploit TacticalAction, result string) *RemediationSuggestion
**Purpose:** Generate defensive recommendations for discovered exploits
**Signature:** `func SuggestFix(exploit TacticalAction, result string) *RemediationSuggestion`

**Usage:**
```go
suggestion := SuggestFix(exploitAction, "Success: Accessed /admin/users")

// Result: RemediationSuggestion struct with:
// - VulnerabilityType: "BOLA"
// - Severity: "CRITICAL"
// - FixDescription: "Implement object-level authorization..."
// - CodeSnippet: Go/Python middleware example
// - ImplementationURL: OWASP documentation link
```

**Returns:**
```go
type RemediationSuggestion struct {
    VulnerabilityType string // BOLA, BFLA, SSRF, etc.
    Severity          string // CRITICAL, HIGH, MEDIUM, LOW
    Exploit           string // How it was exploited
    FixDescription    string // Plain English fix
    CodeSnippet       string // Language-specific code
    Language          string // "Go", "Python", etc.
    ImplementationURL string // Documentation link
}
```

## Example Workflows

### Workflow 1: Automatic K8s Exploitation Chain
```
Step 1: Operator runs "commit"
        ├─ ExecuteStrategicPlan() fires CLOUD_PIVOT action
        ├─ CLOUD_PIVOT accesses 169.254.169.254
        └─ Returns: "k8s_token: eyJ0eXAi..."

Step 2: Automatic Processing
        ├─ ProcessExploitResult() detects "k8s_token"
        ├─ Generates CROSS_TENANT_LEAKAGE action
        │  └─ PreCondition: "loot_from_1"
        │  └─ ChainID: "chain_1_1707325843123456789"
        ├─ Queues to ActionBuffer
        └─ Logs: "[green]✓ ACTION QUEUED: CROSS_TENANT_LEAKAGE"

Step 3: Operator runs "ProcessChain chain_1_1707325843123456789"
        ├─ Validates PreCondition: "loot_from_1" exists ✓
        ├─ Executes K8s API calls with token
        ├─ Captures namespace list + secrets
        └─ Stores in DataSilo: "k8s_namespaces_1"

Step 4: Blue-team mirror
        ├─ SuggestFixAndLog() generates fix for CLOUD_PIVOT
        ├─ Output: "Restrict metadata access, use IMDSv2"
        ├─ Code snippet: Go firewall rules
        └─ Displayed in F5 Analysis tab
```

Step 3: Operator approves chain

## Thread Safety Notes

1. **ActionBuffer**: Not explicitly locked - relies on sequential execution in goroutines
2. **DataSilo**: sync.RWMutex locked for all access - safe concurrent reads
3. **GlobalNeuroCore**: sync.Mutex in NeuroEngineCore - serializes analysis
4. **TrafficHistory**: sync.RWMutex - safe for concurrent sensor updates
5. **LogBuffer channels**: Non-blocking sends with fallback (safe for TUI)

## Performance Considerations

### ApplyJitter() Impact
- ~1ms overhead per request (Box-Muller calculation)
- Recommended for strategic/slow reconnaissance phases
- Can disable for fast scanning with `jitterDelay := 0`

### ProcessExploitResult() Impact
- ~50-100ms analysis per exploit
- Runs in separate goroutine (non-blocking)
- Pattern matching on loot (string-based, O(n) complexity)

### SuggestFix() Impact
- ~20-50ms for fix generation
- Leverages pre-computed templates (no LLM calls)
- Minimal UI impact (logged async)

## Error Handling

### Invalid PreConditions
```
If PreCondition key not found in DataSilo:
[yellow]CHAIN:[-] Skipping action 2: PreCondition 'k8s_token' not met
[red]Precondition failed:[-] 'k8s_token' not found in DataSilo
```

### Empty Chains
```
If no actions match ChainID:
[yellow]CHAIN:[-] No actions found for chain 'invalid_chain_id'
```

### Loot Capture Failures
```
If loot cannot be parsed:
[yellow]Sensitive data detected:[-] []
(No actions generated if patterns don't match)
```
